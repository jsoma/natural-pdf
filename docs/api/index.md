# API Reference

This section provides detailed documentation for all the classes and methods in Natural PDF.

## Core Classes

::: natural_pdf
    options:
      show_source: false
      show_bases: true
      inherited_members: true

The OCR methods on pages, regions, flows, and collections come from a shared
contract mixin. They are rendered here as inherited members so the public
signature and return type remain visible on each host class.
